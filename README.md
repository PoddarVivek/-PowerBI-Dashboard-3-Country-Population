# 🌍 PowerBI Dashboard – 3 Country Population Analysis

This project presents an interactive **Power BI dashboard** that analyzes population data for three countries.  
The dashboard provides insights into **population growth trends, demographic comparisons, and key statistics** using visual analytics.

## 📊 Features
- Population growth comparison
- Country-wise demographic insights
- Interactive filters and visuals
- Comparative analytics between countries

## 🛠 Tools Used
- Power BI
- Data Visualization
- Data Cleaning
- Excel / CSV dataset

## 📂 Project Files
- `PowerBI-Dashboard-3-Country-Population.pbix` – Power BI dashboard file
- Dataset used for visualization
